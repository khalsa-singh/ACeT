# HIC model source

`bailly_hic_model.py` defines the token encoder and alternative heads. `panel_A_D_parity_featureimp_EDITED_v2.py` performs fold-local HIC preprocessing, training and OOF prediction. `reproduce_bailly_from_oof.py` is the lighter postprocessing route.

Use the repository-root commands and schemas in `README.md`; they supply the packaged paths and preserve archived results. Model fitting and archived-prediction recalculation are separate operations.
