# Benchmarking, robustness and diagnostics

- `hic_benchmark/`: repeated OOF antibody HIC prediction, comparator reference and triage.
- `robustness/`: fixed-holdout training-seed stability, alternate-partition predictions and clinical external-cohort summaries.
- `diagnostics/`: head comparisons, pooling sensitivity, copula diagnostics, clinical uncertainty and loss-curve sources.

The root README maps these files to Tables S2–S13 and Figures S1–S11, with separate commands for archived-result recalculation, new model fitting and MATLAB rendering.
