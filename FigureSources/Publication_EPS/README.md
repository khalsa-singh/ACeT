# Main-figure EPS sources

This folder contains the complete Figure 1 and individual panels Figure 2a–e, Figure 3a–d and Figure 4a–d: 14 distinct EPS sources. Panel names correspond to the article. Figure 1 is best placed at the full available text width.

Figures 2a and 2b were exported from the manuscript's SVG artwork to preserve translucent marker appearance. Their EPS files combine vector elements with high-resolution flattened transparency regions. The SVG/PDF counterparts remain available in the main source folders. Root checksums identify the supplied files.
