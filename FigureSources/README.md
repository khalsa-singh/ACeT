# Figure sources

`main/` contains the Figure 1 editable schematic and the data/scripts for Figures 2–4. `supplementary/` contains the S1–S11 plotting sources and publication exports. `Publication_EPS/` contains one final EPS for each main panel, including the complete Figure 1 schematic.

The full figure/panel-to-result guide and execution commands are in the root README. Root checksums cover all assets. File names containing `current` identify a retained producer/output name; they do not select a hidden alternative version.

Use the provided Python commands for numeric plot-source generation and the MATLAB commands for the publication-style renderings. The SVG/PDF/EPS versions are for reuse in documents, while PNG previews are convenient for inspection.
