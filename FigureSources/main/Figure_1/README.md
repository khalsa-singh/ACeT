# Figure 1: ACeT architecture

The reviewed flat schematic is supplied as an editable PowerPoint and SVG/PDF/EPS exports with a matching caption. It shows value/identity token embeddings, pre-normalization attention and feed-forward residual stages, pooling, alternative prediction heads and the four applications. KAN is highlighted only to illustrate the selection route.

No model dimension is imposed by the schematic. Endpoint-specific dimensions are documented in the main guide and model settings. Use the editable PowerPoint for layout changes and regenerate matching exports when the drawing is deliberately changed.
